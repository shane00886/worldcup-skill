# 飞书应用上架发布

## 上架前准备

### 所需物料

| 物料 | 规格 | 备注 |
|------|------|------|
| 应用图标 | 1024×1024 PNG | 品牌化设计，不要通泛名词 |
| 应用名称 | 中英文 | 如"世界杯机器人 / Worldcup Bot" |
| 一句话描述 | ≤45字符 | 如"2026世界杯AI智能助手" |
| 产品介绍图 | 1600×1000, 16:10, 1-5张 | 展示核心功能 |
| 帮助手册 | 云文档或公开URL | 使用说明 |
| 隐私协议 | 文档 | 需补充 |

### 必备权限

| 权限 | 用途说明 |
|------|---------|
| `im:message:send` | 发送消息到群聊或私聊 |
| `im:message:send_as_bot` | 以机器人身份发送消息 |
| `im:message.group_msg` | 接收群聊消息（@机器人） |
| `im:message.p2p_msg` | 接收私聊消息 |
| `im:chat:readonly` | 读取群聊基本信息 |

## 上架流程

### 1. 填写应用信息
在飞书开放平台 → 应用详情 → 版本管理与发布 → 创建新版本

### 2. 填写产品介绍文档
包括：产品简介、用户画像、竞品分析、合作计划、接入计划、收费方案

### 3. 填写安全自检清单
- 通用规范：隐私保护、商标检查、内容审核
- 机器人规范：欢迎语、@回复、群聊响应
- 安全合规：权限说明、数据安全、大模型安全
- 递交声明

### 4. 提交审核
提交后等待飞书平台审核（通常 1-3 个工作日）

## 上架后维护

- 监控用户反馈，及时回复
- 定期检查权限变更
- 关注 API 版本更新

## 常见问题

### 审核被拒原因
- 权限申请过多或过少（最小必要原则）
- 缺少帮助文档或隐私协议
- 机器人没有欢迎语或未回复 @消息
- 应用名称涉及商标侵权或过于通泛

### 海外上架（Lark）
- 使用 `open.larksuite.com` 而不是 `open.feishu.cn`
- 需要重新注册应用（海外平台独立）
- 不需要国内 ICP 备案
- 部署在海外服务器（如 Railway）可直接使用
